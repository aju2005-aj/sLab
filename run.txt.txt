Here are the complete, step-by-step instructions to get everything installed and running on your computer from scratch:

### Step 1: Download and Install Node.js
Node.js is the required software that allows your computer to run the backend server and build the frontend application.

1. Open your web browser and go to the official Node.js website: **[https://nodejs.org/](https://nodejs.org/)**
2. Download the **LTS (Long Term Support)** version for Windows (it will be a `.msi` file).
3. Open the downloaded file to start the installation.
4. Keep clicking **Next** to accept the default settings (Make sure the box that says "Add to PATH" is checked, which it usually is by default).
5. Once the installation finishes, click **Finish**.

### Step 2: Verify the Installation
Let's make sure Node.js installed correctly.

1. Open a new **Command Prompt** window (Press the `Windows Key`, type `cmd`, and hit `Enter`).
2. Type `node -v` and press Enter. You should see a version number (like `v20.12.2`).
3. Type `npm -v` and press Enter. You should see another version number (like `10.5.0`).
4. *If you see the version numbers, you are good to go! If it says "command not recognized", you may need to restart your computer.*

### Step 3: Install the Project Dependencies
Now we need to tell Node.js to download the necessary code libraries for our Smart Lab System.

1. Open a **Command Prompt** window.
2. Navigate to your project's backend folder by typing:
   ```cmd
   cd "C:\Users\user\Desktop\New folder\backend"
   ```
3. Run the install command:
   ```cmd
   npm install
   ```
   *(Wait for this to finish, it might take a minute or two)*.
4. Next, navigate to the frontend folder by typing:
   ```cmd
   cd "C:\Users\user\Desktop\New folder\frontend"
   ```
5. Run the install command again:
   ```cmd
   npm install
   ```
   *(Wait for this to finish)*.

### Step 4: Start the Application!
Everything is installed. You only had to do Steps 1-3 once. From now on, you only ever have to do this final step.

1. Go to your desktop and open `New folder`.
2. Find the file named **`start.bat`** (it might just say `start` and have an icon with gears or a command window).
3. **Double-click** `start.bat`.
4. Two black command windows will open. Leave them open! One is running your backend database/API, and the other is running your website. 
   - *(Note: The first time you run this, the frontend window might take about 1-2 minutes to compile the Next.js pages. Just wait until it says "Ready").*

### Step 5: Open the App
- **On this computer:** Open your web browser (Chrome/Edge) and go to `http://localhost:3000`.
- **On your mobile phone:** 
  1. Make sure your phone is connected to the exact same Wi-Fi router as your computer.
  2. On your computer, open Command Prompt and type `ipconfig`.
  3. Look for the number next to **IPv4 Address** (it will look something like `192.168.1.5`).
  4. Open your phone's web browser and type that IP address followed by `:3000` (for example: `http://192.168.1.5:3000`).
